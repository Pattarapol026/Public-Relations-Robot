# ฟังเสียงพูดแต่ละแบบก่อนเลือก

ผมฟังเสียงเองไม่ได้ จึงไม่ขอบอกว่าเสียงไหน "ดีที่สุด" ให้คุณฟังแล้วเลือกเอง ทุกไฟล์พูดข้อความเดียวกัน
ผ่านการแบ่งท่อน การเว้นจังหวะ และปรับความดังแบบเดียวกับที่หุ่นยนต์ใช้จริง

ตัวเลข "ระดับเสียง" คือความถี่เสียงพูดที่วัดได้ (ผู้ชายไทยโดยทั่วไปราว 110–140 Hz ผู้หญิงราว 190–230 Hz)

**ภาษาไทย** — `th_*_intro` คือข้อความแนะนำตัวต่อกรรมการ `th_*_answer` คือตัวอย่างคำตอบที่มีเวลาและตัวเลข
| ไฟล์ | เสียง | ระดับเสียง |
|---|---|---|
| `th_1-Premwadee-woman` | เปรมวดี ผู้หญิง (เสียงหลักตอนนี้) | ~195–200 Hz |
| `th_2-Niwat-man` | นิวัฒน์ ผู้ชาย (เสียงที่คุณบอกว่าแมนไป) | ~125–133 Hz |
| `th_3-Niwat-higher-soft-20Hz` | นิวัฒน์ ยกเสียงสูงขึ้น 20 Hz | ~140–150 Hz |
| `th_4-Niwat-higher-soft-35Hz` | นิวัฒน์ ยกเสียงสูงขึ้น 35 Hz (ใช้เป็นเสียงสำรองของเปรมวดี) | ~153–162 Hz |

**ภาษาอังกฤษ** — `en_*`
| ไฟล์ | เสียง | ระดับเสียง |
|---|---|---|
| `en_1-Ava-woman` | Ava ผู้หญิง นุ่ม อบอุ่น (เสียงหลักตอนนี้) | ~198 Hz |
| `en_2-Jenny-woman` | Jenny ผู้หญิง เป็นกันเอง | ~175 Hz |
| `en_3-Emma-woman` | Emma ผู้หญิง สดใส | ~176 Hz |
| `en_4-Andrew-man` | Andrew ผู้ชาย | ~107 Hz |

เปรมวดีเป็นเสียงผู้หญิงที่พูด "ผม...ครับ" ได้ แต่บริการออนไลน์ของเธอบางช่วงล้ม ระบบจึงให้นิวัฒน์ (ยกเสียง 35 Hz)
พูดแทนชั่วคราวเมื่อเธอตอบไม่ทัน เลือกเสียงที่ใช้ในหน้า Admin → เสียง → "เสียงพูดของหุ่นยนต์"
